# Onsite Fixed Price Agreement Payload Documentation

This document describes the structure and fields of the JSON payload generated by the **Onsite Fixed Price Agreement (Single)** creation wizard implemented in [fixed_price_page.dart](file:///Users/gaurav/Documents/Work/aspect/chumley_navigator/lib/screens/job_details/fixed_price_page.dart).

---

## 1. Schema Description

The agreement creation is structured as a multi-step form. The backend submission payload contains the raw selections, text input, and confirmation options chosen by the operative, along with computed sub-totals and totals for auditing/validation.

### Field Definitions

#### Core Identifiers (Step 1)
*   **`trade_id`** (String, Required): Unique identifier of the selected trade.
*   **`category_id`** (String, Required): Unique identifier of the selected trade category.
*   **`work_type_id`** (String, Required): Unique identifier of the selected fixed-price work type.

#### Scope of Work (Step 2)
*   **`scope_of_work`** (String, Required): The main scope of work text (validated to be $\ge 5$ lines).
*   **`additional_scope_2`** (String, Optional): Additional description of scope, if any.
*   **`additional_scope_3`** (String, Optional): Additional description of scope, if any.

#### Pricing & Materials (Step 3)
*   **`collection_fee_applicable`** (Boolean, Required): Whether a collection fee applies.
*   **`list_price_service_code`** (String, Required): Selected service code. One of:
    *   `"standard"` (Standard Labour Service - £80.00)
    *   `"emergency"` (Emergency Callout Service - £150.00)
    *   `"diagnostic"` (Diagnostic Investigation - £95.00)
    *   `"none"` (Custom Quote / None - £0.00)
*   **`operative_materials`** (Object, Required):
    *   `cost` (Number, Required): Material costs for materials supplied by the operative.
    *   `description` (String, Optional): Description of materials supplied by the operative.
*   **`charge_drainage_patches`** (Boolean, Required): Whether to apply the drainage patch surcharge.
*   **`aspect_materials`** (Object, Required):
    *   `cost` (Number, Required): Material costs for materials supplied by Aspect.
    *   `description` (String, Optional): Description of materials supplied by Aspect.
*   **`ulez_charge_applicable`** (Boolean, Required): Whether the ULEZ charge (£12.50) applies.

#### Labour & Site Summary (Step 5)
*   **`labour_rate_level`** (String, Required): Selected rate category. One of: `"Rate 1"`, `"Rate 2"`, `"Rate 3"`.
*   **`zonal_discount_percentage`** (Number): Applied discount percentage (e.g. `10` for 10% zonal discount).
*   **`other_discounts`** (Object):
    *   `dog_discount_percentage` (Number): e.g. `0`.
    *   `job_duration_discount_percentage` (Number): e.g. `0`.

#### Customer Confirmation (Step 7)
*   **`customer_confirmation_choice`** (String, Required): Customer choice. Either `"Send Estimate to Customer"` or `"Reject"`.

#### Job & Appointment Metadata (Step 8)
*   **`work_order_id`** (String, Required): Reference ID for the current job/appointment (e.g., `"WO-98765432"`).
*   **`customer_email`** (String, Required): Contact email for the invoice/agreement (e.g., `"customer@example.com"`).
*   **`earliest_requested_date`** (String, Required): Date format: `"YYYY-MM-DD"` indicating when the job is requested.
*   **`job_type`** (String): Hardcoded to `"Fixed Price (Single)"`.
*   **`status`** (String): Initial status, e.g., `"Pending Confirmation"`.
*   **`generate_deposit_invoice`** (Boolean): True if deposit $\gt 0$ is required.
*   **`work_commencing_immediately`** (Boolean): True if work starts immediately.
*   **`payment_link_sent`** (Boolean): True if a payment link is sent to the customer immediately.

## 3. Computed Charges Reference Table

This table illustrates how the client-side UI calculates the final values based on individual selections:

| Item | Input State / Selection | Unit Price / Rule | Calculated Value in Sample |
| :--- | :--- | :--- | :--- |
| **List Price Service Cost** | `list_price_service_code: "standard"` | Based on selection code | £80.00 |
| **Materials Charge** | `operative_materials.cost: 35.50`, `aspect_materials.cost: 15.00` | Operative + Aspect material costs | £50.50 |
| **Attendance Fee** | `labour_rate_level: "Rate 1"` | Rate 1 = £90.00, Rate 2 = £110.00, Rate 3 = £130.00 | £90.00 |
| **ULEZ Charge** | `ulez_charge_applicable: true` | Flat rate: £12.50 | £12.50 |
| **Collection Fee** | `collection_fee_applicable: true` | Flat rate: £20.00 | £20.00 |
| **Drainage Patches Charge** | `charge_drainage_patches: false` | Flat rate: £45.00 | £0.00 |
| **Subtotal** | sum of above items | Sum of all selected fees | **£253.00** |
| **VAT** | 20% of Subtotal | standard UK rate (20%) | **£50.60** |
| **Total (Incl. VAT)** | Subtotal + VAT | Total cost to customer | **£303.60** |
| **Deposit Required** | 50% of Total (Incl. VAT) | 50% flat deposit policy | **£151.80** |
